# Recovered research-image preservation

This is a preservation archive, not promotion of any scientific or historical claim.
It preserves all 5,344 recovered image paths as 2,535 distinct PNG objects. The
manifest maps every original path to the archived bytes. No existing accepted
analysis output, failed-run record, refusal, or source video is overwritten.

Of the 5,344 paths, 4,967 match independent saved original-image hashes; 188
were recovered from published archive copies without independent original
hashes, and 189 are equivalent extractions whose original PNG hashes were
unavailable. These qualifications and original failed/refused-run statuses
remain in the manifest and recovery reviews. Content-addressing proves byte
identity of the archived object; it does not resolve historical interpretation.

The 913 context/diagnostic-image review verified regeneration from 16 preserved
videos with the recorded decoder. Future decoder/runtime compatibility and
native application restoration are not established by that check. All images,
including proposed cleanup candidates, remain preserved here and locally.
The historical deletion proposals are records, not current deletion permission.

Review reports and recovery tools have absolute local home/workspace paths
replaced by named placeholders. Original bytes remain in the encrypted private
preservation backup. Configure those placeholders before attempting a rerun.
Private legal correspondence, case-management material, raw chats and original
HTTP cookies are excluded from this public tree. The parent supplement contains
public response-header projections with cookie/trace fields removed.

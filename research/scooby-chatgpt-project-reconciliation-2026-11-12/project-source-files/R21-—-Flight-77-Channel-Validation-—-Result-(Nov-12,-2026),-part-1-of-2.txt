What a constant door value can establish
With a correctly decoded slot, constancy establishes only constancy of that recorded value. It cannot
distinguish a steady physical state from an unwired/default, failed, stale or differently configured source.
Only SF3 is assigned to the door by this map; the same word/bit in other subframes is not automatically
another door observation. A known-state transition joined to the same aircraft and channel would be
useful validation, but none was recovered.

Four different altitude quantities
Pressure altitude is tied to a standard pressure reference. Barometrically corrected altitude applies
a specified pressure setting and conversion. Radio height is a sensor-dependent return relative to the
reflecting surface and aircraft geometry. Terrain clearance requires a consistent geometric altitude and
terrain/position reference. The Flight Path Study labels its plot FDR Pressure Altitude, even where the axis
says ft-msl; that wording supplies no missing geometric calibration. [S8 p.4]

4. Reproducible specification checks
These checks use the recovered specification and database definitions. They do not decode an observed
flight record. A printout mismatch is an implementation question until the actual converter, database
version, inputs and output are joined. It is not proof that the NTSB output is wrong.
Pressure altitude: overlap and duplicated sign
For the 757-3/-3A/-3B format, Boeing Note3C directs omission of W30 bits 12-10 when combining the two
words. The printout separately describes a signed10 fine field and a computed ALT_COA + ALT_FIN. A
literal implementation of that listing can differ from the specification. [S2 p.20; S3
1737-1769,14212-14223]

fine = (W30 >> 2) & 127
pressure_ft = 128 * coarse + fine

Barometer setting: input BCD versus recorded count
Boeing's 29.92 inHg example records octal 5660, equal to decimal 2992; dividing by 100 recovers 29.92.
The same recorded bits interpreted directly as three BCD nibbles produce 11,11,0, outside decimal-digit
coding. The TXT calls the field BCD and supplies no visible decimal scale in that entry. The missing link is
the converter's interpretation, not a demonstrated instrument fault. [S2 p.21; S3 2812-2842]
Radio height: sign location and component order
Move W31 bit12 to the signed14 sign position; place W32 bits1-2 in data positions11-12; retain W31's
lower11 data bits. Boeing's two published examples test different failure modes. [S2 p.27]

## Derivative method and controls

Adapt the existing scientific full-frame sampling pattern, preserving source
hashes, decoder/version/tool hashes and exact commands. Decode from the start
of each file, without input seeking, audio, autorotation, stabilization, crop,
interpolation or new enhancement. Select the first decoded frame in each
occupied source-PTS bin `[kS,(k+1)S)`, using the declared S. Preserve integer PTS
and time base, not a rounded compilation time as a historical clock. Retain
empty bins, errors, geometry changes and diagnostics explicitly; never fill
missing frames or silently restart a failed run.

Save complete native stored-raster RGB PNGs, plus labeled 3-by-4 overview sheets
with at most 320-by-240 thumbnails. RGB conversion and thumbnail scaling are
declared display derivatives, not color calibration. Preserve sample/display
aspect metadata; no angle/area measurement on thumbnails. Keep raw decoder
diagnostics local-only and print only sanitized statuses. Exclusive new
destinations; sources hashed before and after. Ordinary public frame images
may be inspected here under the goal; no redistribution/feedback transfer.

Before historical decoding, synthetic controls test bin membership/boundaries,
PTS parsing, duplicate/out-of-order selections, gaps, nonzero start times,
unchanged input pins, native dimensions, and overwrite refusal. A success exit
alone is insufficient: independently reconcile frame index, PTS/bins, dimensions
and product hashes. Reproduce material selected derivatives in a second run
or through an independent decoder path; report exact scope, not implied full
reproduction. Preserve failed attempts and code revisions if any.

## Visual screening and candidate admission

Root reviews every overview sheet; an independent reviewer screens the same
declared samples without root's candidate decisions first. Each records actual
viewed sheet/sample IDs, candidate intervals, reasons and unresolved views.
Prior knowledge and derivative-source dependence remain explicit. Neither is
a qualified human forensic examiner. Freeze separate screening notes before
reconciling decisions; retain disagreements and all positive candidates.

A candidate requires scene evidence beyond generic flame color: relative
facade grid/edges, foreground rooftop/parapet geometry, neighboring structures,
occlusion and viewing direction. Similar building identity alone is insufficient
for exact shot identity. Zoom/crop/light differences may preserve an admissible
candidate, but must not be invented to force a match. Negative comparators
within the set and plainly different views remain in the coverage record.

Inspect each candidate's complete native frames and adjacent context before
any assertion of figure correspondence. Subsequent dense intervals must be
declared from the coarse locator, with margins, before extraction. Only a
validated continuous segment can support elapsed-duration measurement; montage
cuts, zooms, frame cadence and sound alignment require separate checks.
A figure-like frame does not automatically authenticate the report's scene,
time, emitting window, pulse mechanism, local collapse or deliberate action.

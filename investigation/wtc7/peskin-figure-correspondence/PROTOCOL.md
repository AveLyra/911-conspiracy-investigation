## Declared analysis sequence and limits

1. Inspect the complete report page and two complete target images, verify
   geometry/provenance, then save explicit target masks/landmark choices before
   searching additional candidate pixels. Label any later choices exploratory.
   Added numbers/text, page margins and overlays cannot serve as match evidence.
2. Use admitted one-second samples in [2502,2534) for initial orientation, then
   inspect all decoded frames in that same source-PTS interval if a defensible
   comparison method passes synthetic checks. Maximum1100 selected frames;
   preserve source PTS/timebase, actual interval coverage, duplicate candidates
   and decode warnings. Seeking must retain absolute timestamps, following the
   previously tested seek/no-accurate-seek rule. No automatic retiming.
3. Prefer the smallest geometrical transform the pixels support. Candidate
   crop/translation, axis-specific scaling and affine transforms must be
   explicit; no elastic warp, generative reconstruction, inpainting or frame
   interpolation. A transformed comparison image is an analysis derivative,
   not new historical evidence. Stored1620x1080, SAR8:9 and display4:3 are
   distinct; no unlabelled aspect conversion or physical angle measurement.
4. Define alignment on static structural features independently of dynamic
   flame/smoke regions. Test dynamic correspondence and adjacent-frame
   alternatives after alignment. A best score alone is not a unique exposure
   match; retain repeated-grid aliases, blur/interlace, compression, crop and
   source-generation explanations. Any mask/parameter revision preserves the
   earlier version and its reason.
5. Before consequential matching, use deterministic synthetic controls for
   known crop/resize/translation/re-encoding, distractor/repeated geometry,
   changing dynamic content and flat/uninformative images. Bounds and scoring
   choices must be fixed in an additive method declaration before historical
   scores are computed. Failed controls prohibit the corresponding inference;
   fixing code does not authorize retroactive tuning to a desired frame/time.
6. Use installed trusted media/image tools only. Initial environment has
   NumPy/Pillow but not SciPy/OpenCV in the bundled Python. No dependency
   installation, web upload or unreviewed-source execution is implied. A
   bounded manual/array comparison is permissible if verified for its actual
   limited purpose; do not substitute a complex unvalidated matcher.
7. Bound each compute invocation at five minutes, yield progress rather than
   block for more than60seconds, and use at most2GiB of new derivative storage
   in this unit. Stream numeric screening where possible; keep full-frame
   images only for declared inspection/shortlisted candidates, maximum64.
   Preserve failed runs and do not overwrite frozen outputs. Reproduction uses
   a distinct run and must compare actual scientific outputs, not just exit0.

## Acceptance and inference ceiling

Produce source-pinned candidate frame/PTS sets for each image, explicit
transforms/regions, residual or ambiguity evidence, synthetic controls,
independent review and a source-relative separation interval if identified.
If exact correspondence cannot be supported, state what was tested and why it
is unresolved. No claim of a NIST timing error, calibrated historical clock,
original exposure cadence, thermometry, structural consequence or ranking
follows from this unit alone. Unavailable originals remain a separate limit.
The full charter is not reduced to this task. Generic lessons extend existing
SFB002/004/005 locally pending the unresolved archived feedback destination.

# Pair-key freeze namespace

The first-two-image record uses `anonymous-pair-key.json` as its provenance
pin, a minimal image-only subset of the same verified extraction. The later
full record pins `anonymous-key.json`, covering its own complete selected
image set. Per-image observations and byte identities must copy unchanged;
only the enclosing membership/provenance pin changes. This explicit scoped
namespace prevents waiting for unrelated figure associations or retroactively
rewriting a frozen pair record. No figure labels/captions appear in either key.
This note is declared before either pair record is saved.

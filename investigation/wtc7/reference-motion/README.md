# WTC 7 reference-motion test: recovered research

This package preserves the historical test of a six-reference image-registration method on two WTC 7 camera access copies. The declared Camera 2 configuration admitted **no transform**: the chosen R3 seed failed its own texture gate, and a later, prompted check found its coordinate did not match the described feature. That is a failure of the selected reference configuration, not proof that the footage contains no usable reference or that the building did or did not move.

For Camera 4, the method reported its all-six similarity consistency screen passing on the first 42 sampled images; the final 21 selected images failed all-six admission. Those are findings within an uncalibrated image-coordinate procedure, not a physically calibrated trajectory, acceleration estimate, failure-timing measurement or collapse-cause result. The two-pixel threshold is not a physical confidence bound. See the [report](report.md) and [method](PROTOCOL.md) for the admitted and rejected outcomes and the [computational review](independent-method.md) for its limits.

Original source video, selected frame images, comparison grids, overlays, and synthetic fixture media are not included in this package. JSON result files and procedures are historical outputs, not newly measured event evidence; some local paths within receipts and verification records have been replaced with stable labels. Each label is the full lowercase SHA-256 hex digest of the exact matched UTF-8 path, surrounded by `[local-path-sha256:` and `]`. The same path gets the same label across all files; collisions are checked. These labels may be guessable from candidate paths and are not encryption. [PROVENANCE.json](PROVENANCE.json) records exact original and derivative hashes, path-redaction counts and absent linked items. Markdown gets historical-context prefaces; Python scripts and unredacted output files remain byte-identical to the retained snapshot. The independently named reviewer was a computational agent, not an independent human witness, licensed specialist, or source of new original-camera footage. The source access copies, original scene clocks, reference stationarity, point identities and calibration remain open.

The included procedure and control records can support later replication once dependencies are legitimately supplied. Parsing or synthetic controls do not validate historical footage, the camera geometry or a theory of collapse. No source media or LFS files were uploaded.

A fresh run of the included synthetic control suite passed 11 checks and failed none. A separate recount of saved outputs confirmed 1,608 match rows and 804 fit-status rows, including zero computed Camera 2 fits and 42 Camera 4 similarity-screen passes per template size; the two saved runs’ match and transform JSON files are byte-identical. These checks do not validate the real camera footage or any collapse mechanism.

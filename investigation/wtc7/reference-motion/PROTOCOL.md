# Multi-reference image-motion diagnostic

Declared 2026-09-11 before historical reference matching. Research-only under CHARTER.md (historical local reference `../CHARTER.md`; not included here), Q03–Q05/WP2. The preceding screen (historical local reference `../multiview-onset-review/report.md`; not included here) is known. This is a prospectively specified computational test on familiar retrospective evidence, not a blind event-level validation.

## Question and scope

Do several apparently stationary neighboring features support a common 2-D image transformation over the selected event images? Does the conclusion depend on feature, template size, model flexibility or leaving out one reference? A successful fit is a limited image-registration diagnostic, not camera calibration or physical displacement. No WTC7 roof trajectory, acceleration or causal ranking is calculated in this unit.

Use the existing `multiview-onset-review/refine01` native mode-L images: all 71 Camera2 event selections (indices6593–7104) and all63 Camera4 event selections (899–1350), including previously declared outer bounds. Keep actual source PTS; do not interpolate omitted frames. No new media decoding or acquisition. Pin the previous completed receipt, two selection manifests and refinement declaration, plus each selected PNG/luma hash, source bytes and current code/config/runtime before and after analysis.

An independent computational annotator chooses six distinguishable reference patches per view from the first selected native image, on neighboring structures/street fixtures rather than the target building, smoke, people or vehicles. Save IDs, integer centers, descriptive identity and depth/visibility caveats before automatic scoring. The same annotator inspects fixed evaluation indices C2:6654,6751,6931,7013,7104; C4:960,1042,1162,1259,1350, without seeing automatic results, recording subjective coordinate envelopes or unavailable/ambiguous status. These are AI annotations, not human review or statistical confidence intervals. No hidden failure member identity is assigned.

## Fixed procedure

1. Native arrays must be uint8, two-dimensional, geometry-consistent, source-hash verified and strictly increasing in exact PTS. Configured IDs must be unique, coordinates integral, and square odd templates fully inside the seed. Seed roles are analyst assumptions to test, not established physical stationarity.
2. For each reference, use separate fixed **19×19 and27×27** baseline templates. Require seed standard deviation≥2 Y code values; retain a rejected seed explicitly. Search integer centers within **±24 pixels of that same original seed** in every image. Do not update the template, propagate a prior match, retime or fill gaps. Thus a later passing match is an independent patch-match candidate, not reacquisition of a validated physical track.
3. Compute zero-mean normalized cross-correlation (NCC) for every valid window, using float64. Preserve complete score grids, all undefined-window masks, effective search bounds, winning coordinates, score, and the best competitor outside a Chebyshev radius3 about the winner. Maxima within absolute1e−12 of the best are counted across the entire grid; count>1 rejects as tied, including ties inside the competitor exclusion. Deterministic winner bookkeeping uses row-major order. Undefined/constant patches are not silently perfect matches. Fail closed on malformed/nonfinite inputs; scores are neither probabilities nor coordinate confidence.
4. Retain all independent quality flags: seed texture, undefined score, NCC<0.8, competitor margin<0.02, and winner on any actual search boundary. These are declared **screening thresholds**, not empirically calibrated accuracy claims. Save every rejected result and do not tune thresholds to obtain a camera fit. The baseline is scored too; it is not automatically accepted merely because it supplied the seed.
5. For each image and each template size, fit **translation**, orientation-preserving **similarity** (translation/rotation/uniform scale) and general **affine** image mappings only when all six reference candidates pass the screening gates. No automatic outlier rejection or selected “good” subset. Center/scale source coordinates for numerical conditioning; least squares uses an explicit singular-value cutoff1e−12. Reject rank deficiency or normalized design condition>10,000. Save coefficients, all six residual vectors, RMS/max residual and each leave-one-reference-out prediction error.
6. Report whether both maximum in-sample and maximum leave-one-out errors are≤2 pixels as a **reference-consistency screen**, not an accuracy bound at the building. Record affine signed determinant; flag singular/folded maps, and require positive nonsingular determinant for a camera-consistency screen. Keep results at other errors, model/size disagreements and rank failures. Leave-one-out rank failures remain separate from a successful full fit and prevent the screen from passing. Similarity and affine use their own rank conditions; collinearity alone need not invalidate similarity. An affine model's lower training residual is not proof it better models the camera; held-out-reference errors and geometry must remain visible. No transform is applied to historical source imagery or a target trajectory in this unit.
7. Synthetic tests precede historical scoring: known shifts, brightness/contrast changes, repeated/identical distractors, flat patches, search boundaries, exact translation/similarity/affine point maps, noisy/nonrigid references, degenerate/poor geometry and invalid contracts. Test actual image matching as well as point-fit arithmetic; explicit limitations may be a correct test outcome. Two fresh historical runs must reproduce deterministic products; keep failures and procedure snapshots. A separate reviewer checks arithmetic and disconfirming controls without silently becoming human/expert certification.

## Interpretation and acceptance

Retain a complete candidate/quality/fit/coverage ledger with exact input lineage. Compare independent manual coordinates at their actual scope without converting subjective envelopes to calibrated error bars. A missing reference, a wrong repeated feature or model disagreement limits registration; it does not establish building deformation. Conversely, agreement among references need not transfer to another depth/plane or an extrapolated target location. Common-mode errors, parallax, perspective, zoom-induced template deformation, inherited recording artifacts and integer quantization remain alternatives.

The first material result is whether this fixed method yields usable multi-reference constraints and where it fails. Do not enlarge search, drop a reference or select another model post hoc without a separately declared version. All results remain exploratory image-coordinate diagnostics until actual human checks and geometric calibration. No Faraday bridge, source promotion, filing or sensitive transfer is part of this test. Generic pain points are deduplicated locally while the existing feedback destination remains archived.

The implementation is local NumPy, not an invocation or validation of OpenCV. Synthetic and independent arithmetic checks govern the specific result.

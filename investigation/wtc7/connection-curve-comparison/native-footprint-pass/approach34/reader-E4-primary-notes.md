each distinguishable lower dash body has a separate ID. Empty sets do not

Mixed early red/gold contact, green contact and blue contact are deliberately
conservative. They retain selected visible ink once in separate conflict bands,

not automatically implicated. Some lower pale tan/gray cells near other ink

Each conflict membership is column-local; the machine enforces the aggregate
candidate-route reference, not any proposed submember ownership. There is no
multi-member band requiring an unsupported member-specific route assignment.

compression. The selected conflict rows bound visible ambiguous material;

is that this conservative attribution omits recoverable gold pixels and
over-includes some compression/neighbor ink as candidates. A different

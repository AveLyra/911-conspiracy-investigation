## Reading and recording

Each reader views the unchanged complete native strip and composed page, then
reads all raw context cells in finite column blocks. An exact-white sparse
display may omit only (255,255,255), with the convention explicit. No color or
contrast cutoff, detector, smoothing, interpolation, guessed centerline or
source-image editing. Raw context must be saved with source, code and protocol
pins and checked against the source; a second save must reproduce it exactly.

For each pair and each local route record one entry per target column:
350 E6 and 220 E7 entries per reader. Each has explicit sorted core/fringe
row sets within the target, a status, a reason, boundary flags and reader-local
fragment attribution. Core is confidently attributed visible stroke; fringe
is tentative edge/compression attribution. Neither is a calibrated pre-raster
curve bound. Empty means no cells attributed, not true absence or zero.

Permitted statuses: identified_local_fragment, fringe_only,
no_attributable_cells, identity_conflict and boundary_truncated. Use a separate
local ID for every distinguishable dash body. If pale material cannot be
assigned uniquely between bodies, keep that assignment unresolved; a single
assumed continuous shell path is not a substitute. Where multiple pieces occur
in a column, record a membership map and no fictitious single-fragment ID.
Preserve holes, disputed cells and shared-color ambiguity. Record every selected
cell touching target left/right/top/bottom; a crop edge is not an endpoint.
The context can explain a truncation but is not a silent expansion of the target.

Compact manually authored inclusive column/row runs may be expanded mechanically.
The expansion must not inspect RGB values or choose cells algorithmically.
Preserve those literal instructions and their expanded records. Readers must
record actual viewed/read coverage, prior knowledge and uncompleted portions.
Uninspected columns must never receive fabricated empty or complete statuses.

# Camera 2 / Camera 4 visible-event screening protocol

Declared 2026-09-11 before this extraction. Research-only under the [charter](../CHARTER.md), Q03/Q05/Q10. Existing sparse screens and their broad change intervals are known; this is prospective method declaration, not blind historical preregistration. No unused event-level holdout exists.

## Initial scope and inputs

Use only the preserved Camera 2 (VID-WTC7-001) and Camera 4 (VID-WTC7-003) access copies and the accepted [timing audit](../timing-audit/README.md). Camera labels do not authenticate original recorders, completeness, independence or historical clocks. Source SHA-256 and byte size, the old exact-PTS map, decoded metadata and identity are pinned in the extractor; verify before and after processing. No new acquisition, audio analysis, source enhancement or bridge invocation.

1. Fully decode each first video stream to tightly packed YUV420P, preserving stored dimensions, disabling rotation, autoscaling and output frame-rate conversion. Require even, constant native dimensions and the pinned YUV420P format. Compare **every complete decoded frame** with its old full-YUV SHA-256, in order; reject missing/partial/extra frames. The raw pipe has no timestamps: the join to the old map is justified by ordered byte identity, not a claim that the pipe independently measured PTS. Preserve exact rational PTS from that validated map.
2. Initial screen selection: first presentation frame at or after each integer file second, starting 0 through floor(last PTS), plus the last frame. Coalesce any shared frame and retain selection reasons. This is access-copy time, not September 11 wall time or a certified exposure clock. Expected selection: Camera 2 270, Camera 4 49; verify from the pinned maps.
3. Save the selected frame's first width×height bytes as a native-size mode-L PNG with **unchanged Y code values**. No color/range/contrast adjustment, stabilization, interpolation, deinterlacing or cropping. Luma-plane imagery is a derivative, not calibrated luminance, color, temperature or physical illumination. Hash full raw frames, selected luma bytes and PNG files separately.
4. Make all initial selected images available in ordered 4×4 overview sheets with half-size tiles (BOX resampling), source index and actual file PTS labels outside imagery. Sheets are for screening only. Retain native PNGs for consequential feature inspection. Inventory every product and actual viewing coverage separately for main and independent computational reviewer; neither is a human/expert certification.
5. Before historical extraction, test raw plane layout/order with known synthetic Y/U/V patterns encoded losslessly, including nonzero irregular PTS; test rational sampling, malformed maps, wrong hash, partial/extra frames and output collision. Run historical extraction twice into fresh scopes; compare deterministic products. Record actual runtime/code/protocol/binary hashes, commands and decoder outcomes. Reject unexpected diagnostics; retain local-only diagnostics and a failure receipt without treating a failed run as accepted. A watchdog may stop only the child process it started; a tool observation timeout is not itself process failure.

## Interpretation and refinement gate

Describe observable roof/façade features, neighboring structures, smoke/foreground obstruction, camera translation/zoom and possible editorial changes. One-second sampling cannot exclude intervening motion or cuts. Use “no abrupt sampled-view discontinuity detected” only where supported, never “continuous recording” from monotonic PTS or selected images alone. Disappearance is not necessarily descent; apparent scene motion is not necessarily building motion. Report contrary panels.

After the overview, declare candidate refinement intervals **before** extracting additional frames. Use exact native indices/PTS and an explicitly stated sampling rule, including retained bounding frames. A frame-wise refinement remains an appearance/onset candidate, not hidden structural timing. Shared cross-camera events require corresponding visible features and uncertainty, not shifting views to agree with a proposed collapse sequence. If alignment is not identifiable, retain a bounded non-alignability result and the missing input.

No displacement/acceleration fit, force estimate, footprint measurement, structural-failure timing, cause ranking or physical-engineering conclusion is authorized by this screening protocol. Later measurement requires calibration, camera-motion references, visibility masks, annotation uncertainty and qualified review as set out in the charter.

Technical grounding: FFmpeg 7.1.1's [pixel-format declarations](https://raw.githubusercontent.com/FFmpeg/FFmpeg/n7.1.1/libavutil/pixfmt.h) identify planar YUV420P; [image utilities](https://raw.githubusercontent.com/FFmpeg/FFmpeg/n7.1.1/libavutil/imgutils.c) describe compact plane layout. Actual known-pattern lossless round-trip tests, not documentation alone, gate this extractor. The raw encoder source URL returned a web fetch/cache error; it was not used as verified support.

## Consequence and strongest counterinterpretation

There is no finite two-sided east-to-west disappearance interval from this
root pass. Combining the conditional onset upper bound and last visible west
frame permits only the conservative lower enclosure **24101/2997 seconds**
(about 8.0417 encoded seconds). It has no finite upper end from these
observations. It is not a model mismatch test, an original-camera-clock
measurement, or a probability statement.

The strongest counterinterpretation is that this native-resolution pass is too
conservative: a higher-quality source, a preregistered lossless display aid, or
a qualified independent observer might trace the west crossing and narrow the
east onset. Conversely, incorrect component association or smoke-driven edge
changes could weaken even these conditional bounds. Separately frozen
annotations and a later explicit sensitivity pass can test that issue; they
must not replace this original record silently. No cause, support-failure
mechanism, actor, intent, or change in overall cause ranking follows here.

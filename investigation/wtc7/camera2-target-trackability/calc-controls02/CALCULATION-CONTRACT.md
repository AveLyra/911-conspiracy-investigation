# Target-coordinate calculation contract

Implementation details for the frozen protocol, recorded before calculating the two historical annotation sets. No annotation, protocol, source or reference fit is revised by this contract.

- `box(xy, halfwidth)` is an axis-by-bound array `[[xmin,xmax],[ymin,ymax]]`. Numeric inputs must be finite and bounds ordered. Annotation centers and strictly positive halfwidths must be native integers, with no boolean substitutions.
- `subtract_boxes(current, baseline)` encloses all possible current-minus-baseline coordinates by `[current_low-baseline_high,current_high-baseline_low]` per axis. Comparing a baseline observation with that same observation gives exactly zero displacement; this shared-variable identity is handled separately, not two independent errors. Other-frame intervals conservatively retain both envelopes without asserting independence or a probability model.
- A displacement requires both observations to be localized and appearance-consistent. A visible but changed/uncertain corner can still be compared for coordinate agreement, but supplies no same-feature displacement. The first definite downward *selected sample* requires displacement's y lower bound **greater than zero**, not merely an interval excluding zero. Include the immediately preceding scheduled sample/status without claiming an onset bracket.
- Inverse-map sensitivity uses the saved map `q=A p+b` as `p=A^-1(q-b)`. Check both current and baseline map admissions. Retain each of six model/size attempts for every annotation row, including failures. Finite positive-determinant matrices with finite two-norm condition no greater than 10,000 are eligible for this numerical inverse; this additional consumer guard is not a physical validity test.
- Transform all four current and baseline envelope corners, take per-axis enclosing bounds, and subtract those boxes for conditional mapped displacement. Retain raw displacement and mapped-minus-raw center displacement. The map is treated as fixed for this sensitivity calculation; reference-fit uncertainty is not included in the rectangle or model spread.
- Determine whether the inverse-mapped center is outside the convex hull of the six baseline reference centers; report that extrapolation, not a fabricated calibration. A hull boundary tolerance of 1e-8 in the cross-product calculation is a numerical classification convention only. Current and baseline matrix conditions are retained.
- Each analyst supplies 34 rows. Results retain 68 individual observation/displacement rows, 34 cross-analyst comparisons, 34 per-analyst between-target comparisons, 408 model/size attempts, and four target/analyst first-selected-sample summaries. Missing values are explicit, never zero-filled. Baseline target IDs/seed coordinates and shared familiarity do not make the two annotators independent historical sources.
- Historical calculations require a passing preserved controls receipt pinned to the current calculation code and contract. Synthetic controls cover inverse shear/translation, envelopes, invalid/singular inputs, localization versus identity, dependent baseline subtraction, sample-gap/onset labeling and a shared-error counterexample. Independent arithmetic review and a second deterministic historical execution are required before reporting the bounded result complete.

No automatic target tracker, acceleration fit, physical interpretation, whole-building symmetry conclusion or causal inference is authorized. This remains a retrospective native-image observation and sensitivity record.

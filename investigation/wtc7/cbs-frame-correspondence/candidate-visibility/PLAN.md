## Required observation record for every image

Record these six categories, with a short image-specific reason:

1. **Region correspondence:** reference target / corresponding candidate
   region / partial candidate correspondence / unresolved correspondence.
2. **Coverage:** full target neighborhood / partial / unobservable, identifying
   crop, banner, foreground or veiling. This is qualitative, not an area fraction.
3. **Aperture or framing edges:** resolved / partly resolved / unresolved. State
   which boundary is actually visible; darkness alone is not an aperture test.
4. **Surface detail:** localized surface-like patch or edge / ambiguous tone
   only / no useful surface detail. Describe the actual cue and alternatives
   such as shade, framing, interior/facade material, reflection or transparent
   glass. Do not infer a material merely from pale or dark color.
5. **Specific discriminator:** a described candidate cue that could distinguish
   partial remaining material, a continuous surface, or a through-opening,
   versus no resolved discriminating cue. A candidate cue is not certified glass
   or proof of absence; state its strongest competing interpretation.
6. **Fitness for a window-state test:** supports a specified conditional
   appearance comparison / supports region location only / insufficient even
   for region location. Describe why and keep floor/time/model joins separate.

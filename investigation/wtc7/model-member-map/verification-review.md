## Independent implementation

`verify_member_map.py` uses a typed fixed/comma-card state machine, explicit
shell connectivity/thickness pairing, separate beam endpoints and orientation
reference, documented old/new solid layouts, and exact known include targets.
It streams with a 512 MiB per-file uncompressed cap and 65,536-byte line cap;
only allowlisted numeric structures and narrowly normalized/hash-only headings
are retained. Node coordinates stay in compact in-memory arrays. Source
geometry is not written as a full node dump. Targeted set2 element summaries,
aggregate part/plane summaries, source hashes, and diagnostics are permitted
derivatives.

The assembly calculation collects definitions and nodes, then independently
streams connectivity. Node/part incidences are deduplicated as integer pairs.
Per-part unique node counts are consequently distinct from global unique nodes.
The diagnostic plane's PSID resolves to a part set; the set's complete node
union is not represented as the solver's actual plane-intersection selection.
Simple mesh-node means and envelopes are not physical mass centroids or member
capacities. Thermal joins refer to the supplied TS coefficient, with TB/LCID
retained, not to a solved or observed Celsius temperature history.

The observed include namespace is checked against the declared numeric cards:
node/element offsets zero; part/material offsets +1000; IDROFF +1000 for
section/hourglass; set offset zero. FCTLEN=1 and TRANID=0 support unchanged
geometry for this include. The numeric FCTTEM=1 token is not treated as a
documented arbitrary temperature multiplier; its historical accepted-input
convention remains qualified by the source review. Only the part/section/
material references used by this join are reconstructed; no whole-solver
namespace or material-law validation is claimed.

## Interpretation boundaries

- A set2 match is a supplied candidate-list membership, not an active deletion
  or an observed historical failure. The unreferenced Case A list receives an
  aggregate coverage/overlap result, not an invented purpose.
- A normalized column label identifies a model-authored diagnostic association
  through PSID and a part set. It is not an original drawing/member crosswalk.
- Node-incidence thermal summaries neither prove that a whole physical column
  had that temperature nor identify a failure mechanism.
- Correct parser arithmetic does not validate material behavior, connections,
  numerical integration, historical executable identity, a restart sequence,
  or agreement with recordings. It does not establish innocence, wrongdoing,
  demolition, fire causation, or legal withholding validity.

## Bounded perceptual capability trial

A separate agent prepares one local synthetic speech fixture containing six
random digit words, using installed offline synthesis. Save the transcript and
generation receipt separately; reveal only a neutral audio path, format,
duration and integrity hash to the root listener before its response freezes.
No historical source or sensitive data enters the fixture. No external audio
service, dependency installation, credentials, payment or model change.

The root attempts the provided audio-content route once. One additional attempt
on the same bytes is allowed solely for a documented transport/schema failure,
not to improve an incorrect answer. No transcript, ASR, spectrogram, waveform,
sample-feature inspection or ground-truth read may supply the root response.
Record either the perceived six words or explicitly no perceptual audio access
in a saved response before revealing the ground truth. The fixture generator
then scores exact ordered agreement. Retain every failure. A tool acceptance
receipt alone is not success. A delivery rejection or no perceptual input means
this route has not established a capable listener; it says nothing universal
about other models, products or a human's ability to play the file.

Even six correct words would establish only elementary access on that synthetic
fixture, not expertise, historical source authentication, transient detection,
timing accuracy, noisy-speech reliability or an accepted scientific annotation.

## Listening procedure if access is established

Complete the four entire excerpts in the table order at original speed, stereo,
with no denoising, normalization, channel mixing, time stretching or event
markers. Record playback route, listener, qualifications, prior exposure,
channel/gain information actually known, coverage and failed/partial playback.
Keep digital playback settings distinct from unknown physical hearing level.

First pass: record all candidate sounds in neutral language, including speech,
rumble, sharp transient, apparent edit and unknown. These are perceptual
descriptions; traffic or other source attribution is a separate tentative
interpretation. Allow at most two additional whole-excerpt passes for location
and uncertainty; stop at three passes per excerpt and preserve disagreements.
Do not replay selectively until a favored interpretation appears. Do not inspect
the old transcript or event labels to supply a new onset. Existing familiarity
is disclosed; this is not a blinded historical analysis.

For each candidate record a local onset interval no narrower than the listener
can defend, any offset interval, channel assessment if perceptually available,
description, alternative interpretation, overlap/masking and uncertainty. Add
the fixed start to both endpoints to express track-relative time. If timing or
category cannot be judged, record it as unresolved. Record a complete-coverage
row even when no candidate is heard; that is not an absence-of-charges finding.

An actual human or qualified acoustic reviewer must check sounds and annotation
uncertainty before event times carry causal weight. This gate is not supplied by
a synthetic pass, an AI second opinion, or the user's earlier pixel review.
No amplitude comparison establishes sound pressure, device type, synchronization
or detection opportunity. No listening outcome alone ranks collapse causes.

## Failure route and deliverables

If the session cannot perceive audio, stop its historical listening branch and
prepare one specific local human-review packet using the verified held files,
with a blank/unheard event record and the same bounded procedure. Request the
missing review once; do not fabricate empty-event findings or keep repeating
the capability test without changed conditions. Continue independent charter
work where useful. Specialist engagement, fees and external transmission still
require separate authority.

Preserve this protocol, source-check receipt, fixture generation and frozen
response/score, actual delivery outcome, a concise result and next action.
A separate source reviewer verifies bytes/format/source offsets without
listening; a final method review checks that failure and inference limits are
not hidden. Reconcile the existing status/feedback records without duplicating
an already logged software limitation. No commit, push or publication.

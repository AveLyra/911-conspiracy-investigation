# Original assembly-test / retrospective-comparison audit

Declared September12,2026 local before this unit's substantive new source work.
The preceding connection-calibration audit made progress but relied on TN1749's
description of the original Thompson2009 experiments. This unit closes that
specific provenance gap where feasible; it does not redefine the full charter.

## Scope and evidence

Start with the complete Thompson bibliography entry in the preserved TN1749
(July2012, correctedFebruary2013), then acquire the exact original from its
institution, author or publisher. Initial search cap10 targeted queries, with
separate exact-route outcomes and no generic unavailable-model search. Preserve
source URL, edition, byte hash and access/marking limits. Public retrieval is not
blanket permission for sensitive disclosure; inspect candidate markings before
displaying new text. Exclude the held packet, flagged command documentation,
private correspondence and arbitrary production payloads.

Identify experimental specimens versus test executions; reused components and
order; restraints, gaps, bolt pretension, loading/control/rate and temperature;
instrumentation, data-processing conventions, missing or failed records; peak
load, associated deformation/rotation, failure modes and post-failure response.
Keep original records separate from later NIST models and later retellings.

Review complete selected pages and all compared table continuations, figure
axes, captions and footnotes. Exact physical/printed page mapping is required.
Do not infer an unreported physical temperature from an indoor photograph or
call a numerical preload temperature a fire test. A load-to-failure test with
no initial column support is not automatically a sudden-removal dynamic test.

## Comparison and calculation gates

Include all rows and both models in TN1749 Tables3-3/3-4, and every original-study
row that maps to the same reported experiments; preserve missing tests instead
of dropping or filling them. Freeze a numerical subprotocol and separate source
transcriptions after inspecting the actual fields but before calculating new
discrepancies. Check means, stated variability and percentage comparisons with
explicit denominator, sample-versus-population convention and rounding limits.
Retain differing span/chord/rotation definitions; no silent conversion chosen
to improve agreement. Do not digitize plots or manufacture raw histories.

The source reviewer acquires the original and extracts conditions/measurement
provenance independently of root's TN1749 reading. A separate numerical reviewer
freezes its table transcription/calculation before root output access. Root
does synthesis and verification. Any later shared-schema adaptation is labeled
post-freeze, not independent discovery. Retain failures and disconfirming results.

## Acceptance and authority

Deliver a primary-versus-retrospective source/conditions crosswalk, reproducible
all-row numerical comparison when supplied data permit, separate inference
review and exact missing-data limits. This may strengthen or weaken a particular
validation claim; it does not by itself validate WTC7 connections or identify a
collapse cause. Distinguish fitted comparison from unused prediction evidence.

Research-only edits in this investigation worktree, no main/canonical/legal
changes, source rewriting, commit/push, solver, property substitution, paid
access, outreach, accepted Sherlock finding or Faraday invocation. Local generic
feedback stays deduplicated under the existing archived-destination boundary.

## Connection to the model and strongest objections

Physical443 describes prescribed photographic window breakage and linear
interpolation where imagery is missing. Its explicit2:00start example is
Floor7, not these Floor12 windows. Physical448 describes similar Floor12
removal assumptions and reports that the prescribed pattern affected fire
direction. Neither page gives the actual removal values for the three targets.
This is a confirmed method statement, not independent validation or a newly
discovered inconsistency.

The strongest objection to a negative reading of this pilot is that better
originals and reliable photographic registration may support NIST's judgments
even when the compressed report images do not permit our independent
confirmation. Failure to verify is not
falsification. Conversely, a report's detailed per-window prose cannot become
independent observation merely because two AI readers repeat it. Shared images
used to prescribe the model could test transcription consistency, but would
not become untouched predictive-validation data.

The [native-input locator](native-input-locator.md) gives exact search scope,
positive holdings and archive/body exclusions. Four public web queries and
the official repository page supplied no native window file in this bounded
check; [search record](validation.md#public-metadata-search) preserves that
limited result. Neither search establishes global unavailability, unlawful
withholding, fabrication or intent.

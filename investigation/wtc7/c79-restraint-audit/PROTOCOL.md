retrospective with respect to the already read structural-chain and member-map

historical run reconstruction, causal ranking or legal-record promotion.

## Question and source boundaries

Can the accessible source reports and released geometry identify the restraints
remaining around the model region attributed to Column 79, rather than treating
loss of bracing as complete simultaneous disconnection?

The source arm starts with NCSTAR 1-9 physical pages 639–641 and NCSTAR 1-9A
physical page 130, including complete captions, legends and continuing text.
It records reported states by floor/direction, and seeks an explicit coordinate/
floor/member crosswalk where necessary. A report diagram is model output or
description, not historical measurement. Source extensions are logged, not
represented as prospectively selected pages.

The input arm uses preserved SRC-116–121 under the same pinned bytes and
explicit include offsets as the member map. The three geometry streams are
the master, transformed outside-region include and mass include; the two
damage lists remain separate unused candidates. The thermal stream is not
reinterpreted in this unit. Source comments, arbitrary titles and unknown
keyword strings are suppressed or hashed. No source text is executed.

## Declared first input test

1. Re-establish the normalized Column 79 diagnostic → part set → part join.
   Do not select a physical member because its integer identifier is 79.
   The previous map's PID 179 result is prior knowledge, not blind discovery.
2. Collect **all physical vertex IDs** of every element in the selected part
   set, with family, effective part ID and source-line provenance. Beam
   orientation nodes are not endpoints. Keep the seed-region envelope; do
   not presume it covers the whole architectural column.
3. Across all three geometry streams, collect every element outside the seed
   parts that shares at least one seed node. Preserve complete ordered
   physical connectivity, matched seed IDs, source lines, effective namespaces
   and coordinates. Distinguish same-node incidence from a rigid coupling,
   tied interface, contact, or finite stiffness/capacity. Do not turn a graph
   connection into a load-bearing connection, or a missing graph edge into
   proof of disconnection.
4. Inventory constraint/contact/boundary keyword families and numeric cards
   relevant to extending this graph. Do not interpret a previously unreviewed
   card schema or silently assume defaults. Exact shared-node incidence is
   the first reproducible layer, not the final restraint reconstruction.
5. Retain available part/section/material references for incident parts and
   mark missing definitions. Keep candidate damage-list intersections typed;
   matching a discrete-element ID to a beam list does not establish deletion.
6. Group descriptive coordinate results only by exact supplied coordinate
   values unless a later declared clustering rule is needed. No automatic
   story labels, north/east directions, dimensional units, effective bracing
   lengths or physical capacities without the necessary source crosswalk.

## Reproduction and uncertainty

Freeze root and independent outputs before comparing numerical arrays. Use
separately implemented extraction for the diagnostic, seed nodes and all
direct incident records; shared originals and prior scope are acknowledged.
Require exact ID/source-line/namespace membership and exact parsed numeric
coordinate agreement, not a post-hoc geometric matching tolerance. Preserve
failed outputs and any revised protocol/code. Two root full passes must agree
on scientific fields; changing command/runtime metadata is separate.

Controls must exercise endpoint versus orientation-node selection, shell
thickness pairing, transformed part namespaces, shared versus merely coincident
nodes, no-neighbor cases, duplicated/shared nodes, missing-node/reference errors,
and source/output preservation. List what each actual test covers. Numeric
verification is not engineering validation; agent review is not licensed
structural expertise.

## Acceptance and next discriminators

Produce a source-pinned reported-state matrix plus independently reproduced
input graph, with explicit distinction between the two. Identify actual
resolvable couplings or the precise missing/unsupported cards and member-state
joins that prevent a directional restraint calculation. Do not stop at a
generic claim that "more data are needed" if a named local dependency can be
inspected. Equally, do not fill missing spring/contact/material/load/history
values to produce a runnable substitute.

A later stability or dynamic test requires a separately declared, physically
supported section/splice/imperfection/load and directional-restraint model.
An Euler length ratio or prescribed support-removal replay cannot establish
this building-specific fire-to-buckling link. All competing mechanisms retain
the same evidentiary ceiling.

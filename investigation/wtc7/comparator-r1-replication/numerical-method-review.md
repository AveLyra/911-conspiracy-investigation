## Substantive code checks

- `parse_ai()` enforces the exact six source-frame sections in order and
  exactly R1/B1/B2 in each, allowed identity labels and bounded inclusive
  integer y intervals. It preserves original intervals and nulls; no averaging
  or tightening is present. Both original AI notes are separately pinned.
- `parse_human()` retains reported x/y, validates native bounds and constructs
  a separate `[y−1,y+1]` arm. It does not overwrite the original AI arm or infer
  x/radial uncertainty. A range extending beyond the raster is rejected rather
  than silently clipped. The current scope is six declared placements sets,
  not a general human-input parser.
- `difference()` uses all four signed interval operands correctly.
  `qualified_difference()` propagates any ambiguous/unlocalizable identity or
  null required range as unresolved. `both_positive()` requires strictly
  positive lower endpoints against both references; a zero lower endpoint
  fails. No reference is discarded to obtain detection.
- `evaluate()` calculates only the five comparison frames, retaining the
  baseline as input. Therefore each arm has five rows and ten intervals;
  the three separate arms yield exactly 15 rows/30 intervals, including
  unresolved ones. It does not manufacture a baseline-minus-itself enclosure.
- Every ordered triplet of comparison rows is recorded. Only consecutive
  source indices qualify: a gap from434 to441 cannot create confirmation.
  Qualifying starts are cross-checked by the helper; overlapping windows
  remain separate reported windows, not independent experiments.
- `clocks()` uses integer source PTS and `Fraction`, checks the fixed selected
  membership/length, joins to inventory PTS/best-effort timestamps and exact
  stored seconds, then subtracts the baseline time exactly. These are encoded
  source coordinates, not original camera times or physical onset. Actual
  map/source membership is the separate source lane, not a synthetic result.
- Historical calculation checks declared input pins and retains input
  placements, clocks, row states and triplets in output. Exclusive `open('x')`
  prevents overwriting an existing result. The controls run before opening
  historical annotations through the CLI. I did not invoke `--output`.

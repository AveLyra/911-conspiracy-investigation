Native-pixel review

Read-only mapping aid. No human review or historical measurement is accepted by this page. Image pixels are not physical coordinates. Frozen observations are unchanged; this page saves nothing.

Display size

Hover to read a native pixel. Click to lock a point, then use arrow keys to move it one native pixel at a time (clamped at the image edges). Fit can skip native rows or columns when pointing with the mouse; use 100%/200% or arrow keys for exact pixels. Escape clears it. Origin is upper-left: x = 0–1279, y = 0–719, increasing right/down. Zoom or scroll does not change a locked point. Changing image clears it. No autosave, download, export, or acceptance action.

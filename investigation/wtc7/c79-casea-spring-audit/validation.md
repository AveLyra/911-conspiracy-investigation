NumPy2.3.5 and `-B`. Each command must name a new output; do not overwrite
the saved receipts. The actual commands are retained in each receipt.


These are replay recipes, not claims that the suggested new output numbers
already exist. Data and protocol pins deliberately refuse changed inputs.
They are separate fixed-input replays, not a pipeline comparing a newly
generated root03 result. Both comparison adapters use pinned root01/root02;
independent arithmetic uses pinned root01. Output arguments
change only the receipt destination. A new root03 needs its own explicitly
declared and pinned comparison before it can be called independently checked.
All source/canonical/legal/main files remain unchanged by this work.

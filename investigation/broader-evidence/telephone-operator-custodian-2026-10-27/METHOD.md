# Method and limitations

This unit began with the current telephone reports, open-records queues and prior query logs. Exact-string searches for the new interview identifiers and distinct operator/custodian routes followed; unchanged failed PDFCoffee/Drive routes were not retried. One old local HTML link-list was parsed to locate the separate Key-302 reader. An attempted BeautifulSoup import failed; a standard-library HTML parser was used instead. No packages were installed. Search returns and processing failures remain local; search results were locators, not source verification. No personal-directory result was pursued.

Normal public-reader navigation used the visible Jump to Page control. Image URLs were read from rendered DOM image elements. Independently requested queryless URLs returned seven JPEG entities without cookies, sign-in or tokens; gated PDF download actions were not used. SOURCES.json records exact URLs, UTC access, status, media type, format, dimensions, bytes and SHA-256. Raw entities remain local in the verified operational media store. The two FBI interviews are OP01 and OP07; OP02–OP06 are five selected response pages. No complete native PDF or full 36/52/50-page review is claimed.

Each of the seven downloaded pages was opened as a local image and manually read. OBSERVATIONS.json contains safe manual transcriptions/paraphrases with physical reader/printed/form identifiers and native-pixel rectangles. These rectangles locate passages; they are not automated OCR validation. All manual reading was by this same assistant. No independent examiner or separate audit was performed.

verify_sources.py checks saved entities against the preserved metadata and image decoding. SOURCE-VERIFICATION.json records the actual run. It cannot authenticate the uploader, agency release chain, underlying interview accuracy, a physical telephone connection, event semantics or historical clocks. No original carrier replay, operator/PBX reconstruction or laboratory/physical experiment occurred. The full underlying call-identification requirements remain open.

Public material is original analysis, safe source pins, observations, checklist, code/results and revision records. No raw scans, full OCR, signatures, card/network/contact identifiers, raw search returns, browser query tokens, private correspondence or case strategy is included. The public source URLs contain no query parameters. The counsel letter's historical confidentiality language is retained as source context, not authorization or a finding that this independently hosted copy was lawfully released; only our limited public-source research notes/pins are published, not the private-authored letter images.

REPORT.md is the preserved first draft. The final README corrects one locator from the broad item17–18 wording to the actually visible continuing Response(Item11) and numberedentry18 on reader11. The exact diff preserves that change. It changes our locator, not source bytes or a historical account. Earlier reports and the work plan retain their baseline hashes; they are not overwritten or adjudicated.

# Candidate ELKIN21 transmission in the South Arrival recording

November 6, 2026 UTC · B129 / PD07 · Atlantic City operational audio. ## Coverage and controls

- **Five event windows.** A left-channel screen checked **126–217 s** in Arrival Data/Departure Data and **169–259 s** in Ground Control around code **14:28**. It checked **3674–3766 s** in Arrival Data/Departure Data, **6306–6398 s** in South Arrival, and **6221–6314 s** in Local Control around code **15:28**. Only the South Arrival output returned a plausible ELKIN21 token. Ground Control returned taxi/routing-like phrases. The model returned blank or no-audio labels for the two Arrival Data/Departure Data windows and the Local Control window. All five extracts contained nonzero PCM. The blank outputs and a model segment extending past its clip demonstrate screening limits. An unrecognized call sign is not evidence that it was absent.
- **Four introduction and transition clips.** The introduction to AEA #2311 returned an Atlantic City Tower rerecording announcement with **Ground Control, Local Control, Arrival/Departure Data, South Arrival** in that order and the Ground Control time range. AEA #2310 returned its Arrival/Departure Data introduction and a South Arrival introduction after the first section. In the latter, the South Arrival and **1447–1530** reading is at playback **3916.680–3927.760 s**, before the first accepted second-sequence frame at **3931.353 s**. This supplies an additional, voice-based position locator. The Local Control transition did not yield a reliable position announcement in this screen. [NARA AEA #2311 audio](https://catalog.archives.gov/id/7598688)
- **Reproduction.** Source hashes and the model hash were checked before decoding. FFmpeg **7.1.1** trimmed full decoded playback by exact 44.1 kHz sample index, selected the left channel and resampled to mono **16 kHz signed 16-bit PCM**. Each primary clip's sample count matched its intended duration. Whisper.cpp **1.9.2**, English Base, ran locally with `-l en -t 3 -ng -nf -oj` and no initial prompt. The focused clip spans file playback **6360–6395 s**. It uses high-pass **250 Hz**, low-pass **3100 Hz** and **+6 dB** gain. The manifest records commands, SHA-256 hashes and the exact clock brackets.

## Effect on the clock question

The first two rows now have image-level support for **026 at origination**. The carrier interview separately calls **026** Fort Wayne, **059** Columbus and **001** the Oak Brook ground switch. It describes the radio base station field as the origin site and the last-site field as the ground site used at termination. The first row's two site codes and one handoff are consistent with a change of sites within the record. Using the last-site code alone would assign the first row a different site. Both reproductions can come from the same carrier records. Their agreement does not independently establish actual routing or the physical site identity.

# FAA Flight 11 intranet entry: differing chronology time labels

Reviewed 2026-11-25. This is an additive comparison to the [Flight 11 intranet chronology review](https://github.com/AveLyra/911-conspiracy-investigation/blob/df1ad608ad7e877b908392bdce7cfb7bf0e37172/investigation/broader-evidence/faa-flight11-intranet-chronology-2026-11-25/README.md). It does not replace either record.

## Observations

The seven-page FAA **Chronology of Events September 11, 2001**, [AWA-610 UAL93, PDF pages 5–6](https://catalog.archives.gov/medialz/dc-metro/rg-237/7419198-9-11-faa/2-UAL-93/e-Other/2-AWA-610-Chronology-of-Events-Sept-11-2001.pdf#page=5), labels this notice **1305**: “AEA-500 advised that AAL 11 voice tapes on intranet web site; will be taken off and no more data put on web sites.” The eight-page **11 SEP 01 CATASTROPHIC CRISIS**, [AWA-342, PDF page 5](https://catalog.archives.gov/medialz/dc-metro/rg-237/7419198-9-11-faa/5-e-other/5-AWA-342-Timeline-11-Sept-01-Catastrophic-Crisis-REDACT-SEALED.pdf#page=5), labels the same wording **1306**. That version's heading states all times are EDT; the AWA-610 page images reviewed for this comparison do not state a time zone. Treat the labels as an unresolved discrepancy, not as established event times.

The adjacent rows also differ: AWA-610 page 5 labels the NYC lockdown entry **1303** and the USAF/CC Pentagon entry **1304**; AWA-342 page 5 labels them **1304** and **1305**, respectively, and has a separate **1303** “ZBW” entry. This comparison does not establish the origin or meaning of the differences.

Both documents separately label the reported AAL11 data removal **1324** and the proposed AAT-20 placement **1328** (AWA-610 page 6; AWA-342 page 6). Similar wording and sequence suggest possible source dependence; it is untested and these are not independent confirmations. The notice concerns unspecified “voice tapes”; the lines do not identify their content or prove destruction, successful placement, concealment, or intent.

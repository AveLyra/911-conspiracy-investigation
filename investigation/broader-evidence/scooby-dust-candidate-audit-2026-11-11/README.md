# Candidate-by-candidate review: dust specimen lineage

November 11, 2026. This checks the 22 mechanically segmented **visible-summary candidates** for Scooby report 26, not the report's full tables, attachments or every scientific proposition. A published author's description is distinguished from independent replication. Candidate 26-002 is truncated by the extraction, and 26-019–022 describe a proposed experiment rather than completed observations.

Sources: [Harrit et al. 2009](https://benthamopenarchives.com/contents/pdf/TOCPJ/TOCPJ-2-7.pdf), [Millette 2012 progress report](https://www.911facts.dk/resources/Millette/9119ProgressReport022912_rev1_030112web.pdf), and the private saved research-card summary.

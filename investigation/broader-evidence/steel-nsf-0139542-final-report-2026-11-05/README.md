# NSF award 0139542 and the steel field-report trail

November 5, 2026. STL01–STL03 / B188 / H005. The official NSF API identifies award **0139542** as the Berkeley WTC post-disaster reconnaissance project, with a listed period of October 1, 2001 through September 30, 2002. Two NSF API routes returned identical JSON. An archived third-party PDF carries the same award identifier and title. It contains a three-page final form marked submitted November 7, 2005 and approved February 13, 2006, followed by a twelve-page paper. Two replay modes returned identical PDF bytes. The award metadata corroborates the project identifier. The PDF is a preserved mirror of the report, with no authenticated NSF-system download or export manifest.

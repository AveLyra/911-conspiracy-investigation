## Reproducible tape-list comparison

The Box 3 inventory groups **NY1471–NY1496** into four HOST System Analysis Recording ranges. The June 2005 transfer lists those identifiers individually. All **26** identifiers in the grouped list appear in the transfer memo. All **eight** printed group endpoints match the first and last constituent labels when read as UTC clock labels, retaining the September 12 rollover on the last range. This checks inventory agreement. It leaves audio or data contents, completeness, and calibration untested.

For the distinct **NY2116 HOST Core** tape, the Box 3 inventory says **0000Z–0000Z**. The transfer memo says **0400Z–0000Z**. Both describe the tape as blank. Preserve the conflicting start labels, and keep this tape distinct from **NY2044**, for which both lists show **0400Z–0400Z**. Neither range determines whether an actual recorder was operating or whether any other recorder captured a particular event.

## Effective-time strings preserved separately

The public PDF text index displayed **060301700** for the heading of **FDC 6/2550**, including at index lines 3002–3004 and 6608–6609. The downloaded NTSB docket PDF prints **0603011700** on physical p. 20, lines 34–39. That line was visually checked. A search of the PDF's extracted text for the **6/2550 Part 1 of 8** heading followed by the effective field found four occurrences on physical pp. **20, 62, 100 and 139**, each with **0603011700**. Page 28, line 23 also gives **0603011700** in an airport notice referring to both 2006 notices. This records a difference between the index text and the downloaded copy. The source entity used to build the index and the original FAA issuance metadata were unavailable. The four headings occur within one docket attachment.

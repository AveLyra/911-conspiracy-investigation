### A reported steel transfer with different weight descriptions

The March revision describes **a 60-ton piece** donated and melted for the ship, using **“SS New York.”** The Navy's USS New York crest description separately gives **24 tons of recovered steel** and a **7.5 metric ton bow stem**. The Naval Research Laboratory's review reports **more than twenty tons** melted and poured on **September 10, 2003** at Amite Foundry and Machine, and **21,000 pounds** set aside for anchor-handling castings. Keep donated, recovered, poured, set aside and finished weights under the source's own labels and units. The stages could refer to different quantities within the same project, an untested explanation. No weight reconciliation, piece match or WTC 7 attribution follows from the descriptions. ## Acquisition and reading scope

Four official LMDC PDFs were acquired over HTTPS on November 5, 2026. Their SHA-256 values, page counts and exact reading locators are in [SOURCE-PINS.json](SOURCE-PINS.json). Line numbers are one-based on each physical page, counting blank lines, using PyMuPDF 1.27.2.2 default text extraction. The page equality test compares unnormalized extracted text. This was a selected-text comparison. The Navy accounts were read via the public web index, and the direct Navy crest request returned 403. Native Navy bytes and full page visual comparisons were outside the acquired corpus. The study establishes wording differences and record locators. Any original component identification or current custody remains unverified.

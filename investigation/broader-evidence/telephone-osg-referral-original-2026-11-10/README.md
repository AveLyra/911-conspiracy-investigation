# DOJ's 2014 routing entry for September 11 Solicitor General telephone records

Public derivative of the November 10, 2026 source review · TEL01, TEL03–TEL04 / AUD016-A1 / TC05–TC06. A Department of Justice Office of Information Policy (OIP) log supplies a case number for the search for the receiving office's telephone records. The request description specifies the Office of the Solicitor General (OSG) and September 11, 2001. This is a later administrative record about a request for records. The historical telephone records and the receiving office's response are still unacquired.

The case row records OIP's closure and uses “requester and/or request.” It leaves open which form of routing occurred, whether OSG received the request, whether either office located telephone records and what OSG determined or released. OIP's FOIA library describes logs covering a listed set of offices and notes that a log can refer readers to another office. OSG has its own FOIA and electronic reading-room pages. OIP's 2008 routing guidance describes forwarding misdirected requests within a department. The published guidance supplies no case-specific dispatch or receipt date. - All 12 calendar-2014 CSVs were retrieved from DOJ's Older FOIA Logs index and parsed as seven-field records. A screen across 1,020 data rows for the exact ID and a bounded telephone/phone plus Solicitor General subject pattern yielded only the March row. This is an OIP log screen. Any OSG-only tracking number, unpublished disposition or differently worded row remains possible. [Index](https://www.justice.gov/oip/older-foia-logs)
- The OSG FOIA and electronic reading-room landing pages returned no match for the request ID or the phrase `telephone records`. The screen did not enumerate separate agency systems or archives. The FY 2014 archive URL returned HTTP 200 with an HTML browser-verification interstitial. No annual-report contents were obtained from that response.
- The PDF variants are two deliveries of the same bytes. The CSV is a separate representation of the OIP log. Neither the cross-format match nor OIP's procedural guidance independently corroborates an original call, recipient, transfer leg or search outcome.

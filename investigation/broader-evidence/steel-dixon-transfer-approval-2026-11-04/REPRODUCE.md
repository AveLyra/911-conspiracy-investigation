# Reproduce the limited source check

Acquire the exact source URL in SOURCE-PINS.json through authorized public access, retaining the pinned bytes and source version; do not overwrite another capture. Use the verified Intel store for project PDF/raster work.

With existing Python/pypdf:

```sh
python3 verify_source.py --source /absolute/path/to/preserved/source.pdf
```

This verifies120782bytes, the SHA256, ninepages and six exact selected text locators. It does not test authenticity of signatures, execution, shipment, artifact origin, present access, physical behavior or any historical experiment. Full144dpi page1/8/9 visual review was separate. Source text spacing is not silently rewritten. No missing utility installation is required.

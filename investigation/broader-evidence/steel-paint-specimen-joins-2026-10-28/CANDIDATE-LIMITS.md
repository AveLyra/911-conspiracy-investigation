# The seven-item reconstruction is conditional

The README's candidate set explicitly uses the detailed **G.3 nine-panel list**. The preserved **G.2 eight-panel summary** differs by K-1. Applying the same set subtraction to G.2 gives **eight candidates**, including K-1. That is a substantive sensitivity control, not a reason to silently prefer G.3.

TableE1 physical165/printed449 has a positive paint entry for K-1. Thus omission from a WJE summary is not by itself proof of no recovered-technique indication. The seven-item set is a retrieval hypothesis with stated source/region/completeness assumptions; matching NIST's reported total is not independent validation. Actual paint-state and item/region joins, plus the authored seven-panel list, remain required.

Both earlier eight/nine accounts are preserved. No summary count, specimen label or paint observation has been corrected or resolved. See CANDIDATE-SENSITIVITY.json for both input sets and exact derived alternatives. This limitation supplements the README rather than changing its source record.

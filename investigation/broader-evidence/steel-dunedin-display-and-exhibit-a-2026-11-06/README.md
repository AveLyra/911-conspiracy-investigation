# Dunedin memorial display and the G-0118 court-list description

November 6, 2026 UTC · **STL02–STL03 / B188 / H005**. Two city-hosted reproductions of July 2010 Exhibit A describe **G-0118** as **Steel Beam**. Dunedin’s 2015 draft letter names **G-0118v**. The city’s FY 2019 budget supplies two photographs of its installed memorial, and county minutes document that the dedication had occurred by the September 14, 2016 meeting. These records add an object description and a display record. The photograph, court row and transfer letter still lack a shared item-level identifier. The depicted shape is consistent with the broad description **Steel Beam**, which also occurs in neighboring court rows. The comparison establishes no uniquely identifying match. A parent-and-cut-piece relation, a different suffix convention, a recording error and unrelated items with a shared stem remain untested explanations. The original catalog and tagged records are needed to test them.

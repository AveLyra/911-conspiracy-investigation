## Figure and custody check

The March statement reports saving some components and introduces four examples of inspected structures on PDF p. 3 lines 11–15. Its Figure 4 shows the investigator examining an internal column described as struck by a round object (p. 3 lines 33–34). The October report's Figure 4 instead shows the flatbed view with the selection annotation for a column attributed to WTC 7. The public copy of the March letter reports saving steel in general terms. Neither March document supplies an item number or later disposition for the photographed October column. [March statement, figure page](https://digicoll.lib.berkeley.edu/record/291544/files/205-WTC-Astaneh_Testimony-before-Committee-on-Science-at-WTC-Hearings.pdf#page=3) · [October report, Figure 4](https://digicoll.lib.berkeley.edu/record/291534/files/103-WTC-Astaneh_Progress-Report-to-NSF-on-UCB-WTC-Project.pdf#page=4)

The four March figure images were checked visually and with PyMuPDF's embedded-image digest. **Zero exact digest hits** against the 20 image placements on the standalone October figure page or the six on the corresponding supplement page. Placement counts can include overlays and are retained only as test denominators. The test detects reuse of the same decoded embedded image. Cropping, compression, added marks or different views can defeat it. The figures provide no item-level link, and the comparison leaves open whether different views show the same physical object.

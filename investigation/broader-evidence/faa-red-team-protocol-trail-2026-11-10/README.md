## Signed draft response and document identifiers

The February 4, 2005 DHS letter is reproduced on two image pages in GAO-05-457, Appendix V, printed pp. 58–59 (PDF pp. 63–64). Its subject reads `GAO-05-143SU` and `GAO Job Code 440256`. The public report ID is `GAO-05-457`. DHS describes the connectivity plan as fulfilling the first draft recommendation and says steps toward the second were underway. GAO says TSA did not supply the connectivity plan despite requests, so GAO could not assess whether it fulfilled the recommendation. Preserve both accounts. The two actions concern connectivity and training records. GAO separately names its classified covert-testing analysis as `GAO-05-437C` in note 41 on PDF p. 39. Keep all three document IDs distinct.

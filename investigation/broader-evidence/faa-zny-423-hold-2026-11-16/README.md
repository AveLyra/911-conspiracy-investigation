## Source and scope

The [NARA scan](https://catalog.archives.gov/medialz/dc-metro/rg-237/7419198-9-11-faa/4-UAL-175/e-Other/4-ZNY-423-Memo.pdf) ([catalog 7598619](https://catalog.archives.gov/id/7598619)) was retrieved November 16, 2026: one page, 17,705 bytes, SHA-256 `c5156d56c3c48a1770a234f2734be520db2a1c0790b6aecfaaa46bb1514ef4dc`. The whole visible page was reviewed. The [NARA finding aid](https://www.archives.gov/research/foia/faa-finding-aid-72-83) describes it as a request to retain data for UAL175.

## Observation

The document is dated September 17, 2001, from `ZNY-505`, concerning accident package `ZNY-ARTCC-148`. It says the office is compiling the package and asks the listed Boston ARTCC and Bridgeport, Connecticut flight service station to hold data concerning the aircraft under Order 8020.11. It also asks for negative replies where a facility has no data. Its visible event time is `1303Z`. The request does not itself document delivery, responses, the contents of the accident package or implementation.

The scanned page visibly reads `9/11/01` for the event date; MuPDF extraction yields `9/11101`. Both readings and their layers are recorded; the extraction is not treated as an authenticated alternative historical date.

# What the 2004 DOJ accession identifiers point to

Public derivative of the November 9, 2026 Eastern source review · B129 / PD04–PD05 supporting PD01. NARA's public RG 60 catalog export lists both **TR-0060-2022-0041** and **W060-06-0937** in one series, **Class 5 (Tax: Income and Inheritance) Litigation Case Files and Enclosures**, **NAID 7284818**. Its creator is the DOJ **Tax Division**. The accession register pairs those identifiers in a 2004 row with the generic title **“Significant case files.”** The exact identifier match changes how the 2004 lead should be assessed. It points to a Tax Division series and weakens the provisional link to the Commission collection. The register describes one accession and the catalog describes a series. Preserve the titles and date ranges at their recorded levels. The catalog's separate identifier arrays leave individual box contents and any item-level link to the Commission open. The tax-series association comes from the paired register identifiers appearing in the same catalog description. A title or date alone would give a weaker match. ## Scope and verification

The streamed screen read **400 listed objects**, **3,040,176,635 bytes**, and **268,524 JSONL lines** under the captured RG 60 descriptions prefix. It checked title, scope, specified identifier and related fields for the target accession and FRC number, both schedule authorities and Commission collection terms. One description contains the exact ID pair. No matched description names either Commission schedule or the specified Commission collection terms. These results cover the frozen public metadata and the stated field and term screen. The live catalog, unexported metadata, other record groups and actual container contents remain outside scope. [NARA dataset guide](https://www.archives.gov/developer/national-archives-catalog-dataset)

The first checksum pass treated multipart ETags as full-body MD5 and was stopped after 25 receipts. The resumed run reused 19 verified objects. The final receipts verify 288 single-body ETags and 112 composite ETags using two parts split at 8 MiB. The receipt ledger pins SHA-256 for every streamed object and the exact retained bytes for each match. Controls checked the actual FY 2023 accession row, schedule strings and an adjacent-number negative case.

# May 2003 FAA hearing question and follow-up records

November 6, 2026 UTC · **B129 / PD01–PD04 / PD07**. The Commission's **May 21, 2003 draft hearing questions** already use **9:24 a.m.** in a question about notifying NORAD of American Flight 77. At the May 22 hearing, Ben-Veniste attributed the same time to NORAD. The FAA answer read the next day invoked NORAD logs for that time. The chronology matters when assessing whether these statements independently corroborate the time. The actual source that informed the draft question and the source the FAA drafters used remain unverified. [Public archive mirror](https://archive.org/download/911datasets/NARA_9-11_Commission_Records_Released_Jan_14_2009.zip) · [May 22 transcript, physical p. 118](https://digital.library.unt.edu/ark:/67531/metadc1228311/m2/1/high_res_d/9-11Commission_Hearing_2003-05-22.pdf#page=118) · [May 23 transcript, physical p. 78](https://www.911commission.gov/archive/hearing2/9-11Commission_Hearing_2003-05-23.pdf#page=78)

# NORAD September response-time faces and FAA source trail

**November 9, 2026 | B129 / PD01 / PD07.** The public Commission archive yielded the document face for **NCT0072623 / RDOD 04018579**. It is headed *NORAD'S Response Times*, dated **16 September, 2001**, and annotated. The FAA Agency Historian cites a **September 17** source with a similar title. The document face, cited date and September 18 release date are separate observations. The available record does not identify the September 16 scan as the exact document used by the historian.

Those are reported allegations. There is no recording, transcript, authenticated speaker/flight or carrier determination in this unit. “Cell phone” in a tip is not an engineering finding distinguishing cellular from an installed aircraft telephone. The background-noise description is a possibility, not an acoustic result.

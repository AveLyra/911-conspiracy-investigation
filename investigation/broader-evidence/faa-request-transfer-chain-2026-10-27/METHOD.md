# Source reading and reproduction

The four public National Archives PDFs are linked and hashed in ACQUISITIONS.json. Their complete bytes are preserved locally. This public payload contains research notes, source/page locators, selected safe table OCR, manual label readings, source/render hashes and control code. It does not contain the full PDFs, full OCR, page images, signatures, contact/logistics identifiers or concealed values.

Each PDF was opened read-only with PyMuPDF, and each page rendered at 110 dpi with annotations enabled. RENDER-RECEIPTS.json records actual renderer version, page counts, dimensions and PNG hashes. All 37 physical pages were visually inspected. SOURCE-READINGS.json distinguishes blank backs, repeated/annotated versions, unrelated material and substantive pages. The October 2 handwritten page was also rendered at 220 dpi; HIGH-RES-READING.json records its hash. A full-resolution image can be inspected locally; display resizing is separate from the saved raster resolution.

`ocr_visible_pages.py RENDER_DIRECTORY RENDER_RECEIPTS_JSON OUTPUT_JSON` uses local Tesseract 5.5.2, English, page-segmentation mode 3, one OpenMP thread per job, three concurrent jobs. OCR reads only the visible raster, preserving redactions. The original PDFs were never rewritten, and no hidden text layer was extracted. All 37 OCR processes exited zero; this is execution evidence, not accuracy approval. Full OCR remains local.

SELECTED-TABLE-OCR.json retains only the TAPES MADE blocks from R page 5 and P page 2. Their extraction boundary is the displayed TAPES MADE heading through the following EXTRA ITEMS heading. It does not repair letters or time values. LABEL-TRANSCRIPTION.json is the separate manual reading of both images, with scope and timebase limits.

Run `python3 check_visible_tape_rows.py SELECTED-TABLE-OCR.json LABEL-TRANSCRIPTION.json`. The recorded result is **exit 1**, reproducibly: one block matches 14 windows, while the other yields 13 because its OCR has `IMP RE 91351-1359`. Both source images visibly show `IMP RC 1351-1359`. OCR also confuses BTV with BIV. The failed raw control and the visual reading are both retained. No code change or weakened assertion was used to obtain a pass. This controls label transcription; it does not decode original media, certify unique records, authenticate shipment receipt or calibrate clocks.

README.md and REPORT-v2.md redundantly preserve the current native report. REPORT.md retains the preceding text. The version diff adds exact prior-study links and preserves the AAT/ATH office-code distinction; it does not silently revise historical values or claim to resolve a discrepancy. Git diffs under diffs/ record text changes/additions. PDF layout/reading receipts remain separate.

VERIFICATION.json expressly records that all tests did **not** pass. Source preservation checks, manual observations, a failed OCR control and unperformed historical/technical tests are separate. A read receipt, an airbill, a sender's item list and a recipient's payload acceptance are different evidence stages. Earlier source studies remain intact. No source has been promoted into the private litigation fact/exhibit spines.

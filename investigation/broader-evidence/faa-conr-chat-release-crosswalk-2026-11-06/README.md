November 6, 2026 UTC · B129 / PD01–PD04. ## Source labels matter for the early chronology

Document 4, part 1 p. 1, prints **“RADES INFO FROM DRAFT NORAD/PA RELEASE 17 SEP 01”** immediately after the exercise-channel header. The selected opening pages interleave rows tagged **SOURCE RADES** with clocked chat messages. The face has a separate footer **06/10/03 3:18 PM**. Its field meaning and the assembly history remain open. Keep the date in the source annotation, the footer, and the September 11 event labels separate. ## Overlap check

All three page faces show **14:05:25** for the CONR fighter-status request and **14:31:01** for the CONR message reporting authority to intercept and shoot down nonresponsive tracks. The first values appear on doc 2 p. 1, doc 4 p. 2 and doc 5 p. 1. The second values appear on doc 2 p. 1, doc 4 p. 3 and doc 5 p. 1. In doc 5, the public web extraction gives **14:03:25** for the fighter-status request, while the page image and embedded text give **14:05:25**. Preserve the extraction difference separately. The shared rows point to overlapping representations of chat traffic. Counting all three copies would triple-count those messages. The **14:31:01** row is a reported authorization in the chat and leaves the original authorization’s timing and transmission open.

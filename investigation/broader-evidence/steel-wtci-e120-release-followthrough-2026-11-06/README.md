# WTC 7 drawing transfers and the E120 field-work records

November 6, 2026 · Steel track · STL02–STL03 / AUD011 / AUD016 / B188 / H005

Recovered a contemporaneous FEMA-to-NIST transfer memo and the Cantor drawing-legend packet that a later letter says it had sent. The packet documents receipt of a legend transmittal and an offer to make additional records available. Separately, the August 29, 2012 NIST response says the agency found no records responsive to the request for the WTC 7 field-work drawings. The referenced sheets and item-level delivery records remain open. ## E120 field-work drawings

- **The drawing.** **WTCI-000280-I**, physical pp. 1–2, has two field-welding tables. The lower table names **FW10, FW11, FW12, FW13, FW17, FW18, FW25, FW26, FW27, FW30, FW31 and FW32**. The upper table lists **FW11, FW12, FW13 and FW27**. The upper **FW11** row lists details **1, 2, 3**. The lower row lists **1, 2**. Both page views preserve the difference. The applicable revision or scope remains open.
- **The request and response.** The August 29, 2012 final response quotes the July 17 request for all twelve named sheets and any WTC 7 field-work drawings. NIST reports a completed search with no responsive records. The quoted request refers to E120 having been released under **12-009**. The intake log's **12-184** entry instead refers to the E120 description in the release under **12-090**. The drawing, inventory, intake summary and response establish different record facts. The response does not establish that the referenced sheets never existed or that no other custodian held a copy.

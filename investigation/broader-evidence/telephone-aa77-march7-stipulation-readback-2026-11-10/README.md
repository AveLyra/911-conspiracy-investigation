## Reproducible time-window test

Endnote **57**, official HTML raw line **135**, lists **9:15:34 / 1:42**, **9:20:15 / 4:34**, **9:25:48 / 2:34** and **9:30:56 / 4:20**. It describes four connected calls to unknown numbers, says the records leave unresolved which two represent conversations between the Olsons, and separately reports FBI/DOJ's belief that all four were communications with the office. Retain the unknown-number designation and the agency belief together. This is a Commission account citing its underlying records. [Commission endnote 57](https://www.911commission.gov/report/911Report_Notes.htm)

Under a provisional same-clock comparison, these are the memberships of the printed windows. Treating the upper printed minute as an exact :00 endpoint or including the full terminal minute gives the same memberships for these four records.

| Printed window | Endnote 57 starts inside it |
| --- | --- |
| 9:15–9:26 | 9:15:34, 9:20:15, 9:25:48 |
| 9:20–9:31 | 9:20:15, 9:25:48, 9:30:56 |

Even requiring two distinct rows in chronological order leaves **six possible pairs** by time alone. Sorting the four reproduced minute labels and subtracting the four endnote times in order gives **−34, −15, +12 and +4 seconds**. Those differences are arithmetic on displayed values. They leave clock synchronization, rounding conventions, call start versus conversation time, and source dependence open. The test supplies no caller assignment. It also leaves the separately preserved **154 versus 159 seconds** for the 9:25:48 record unresolved.

## C01 — What the index and certifications actually say

**S02, p1**, dated **December 3, 2001**, certifies that the listed copies are true copies of originals on file in the office. It lists **14 record categories**, including original voice recordings, certified cassette rerecordings, partial transcripts, DART, NTAP, SAR tapes and SATORI. Fourteen categories are not fourteen physical items, a complete delivered manifest or proof the underlying originals survive today. The index does not itself provide the voices/data or identify their byte-level relationships. Selected text: p1, lines6–24.

**S04, p1** is a December 3, 2001 memorandum for the Henderson Radar position, covering **1234–1309 UTC**. **S05, p1** is dated May 7, 2002 for the Radar Associate position, covering **1234–1320 UTC**. Each bears a signature image and language certifying a true transcription of recorded conversations pertaining to the accident. S04 p1, lines19–20,29–30; S05 p1, lines9–10,18–19,32–33.

These are explicit documentary certification claims with different preparation dates and position/window labels. They are not independent measurements merely because there are two signatures or positions. A true-transcription assertion is not automatically a complete-master, selected-channel, copy-generation or historical-clock certification. Both records are called **Partial Transcript**.

## Methods, failures and remaining work

Its **event selection** uses words and surrounding sequence while retaining raw extracted text. It does not normalize original time values or infer the physical clock.

An initial script assertion found no exact match for the search cue roger squawk because the older PDF text layer misreads that visible word. The failure and first script remain local; the executed version instead uses the same utterance's preceding phrase **indy center roger**, still requiring one unique source match. No timestamp or source byte was changed, and the unique-match requirement was not waived. A separate initial preparation command used a Python environment without PyMuPDF and failed at import before writing output; the existing correct runtime was then used without installation. These are our processing limitations, not suspicious source findings.

All 23 newly acquired page images were inspected. All new originals and the held F04 match their recorded hashes. These controls verify preservation and the declared comparison, not historical truth or goal completion. [Checklist](CHECKLIST.md) and [open originals](OPEN-RECORDS.md) retain every substantive dependency.

The strongest alternative to a wrongdoing interpretation is that these are openly labeled drafts, later partial transcripts, ordinary copy/correction activities and different recording positions. No cause, motive or controlling historical value is selected.

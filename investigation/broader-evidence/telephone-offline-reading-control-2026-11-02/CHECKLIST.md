# Control and preservation checklist

- [x] Identify a specific previously unperformed audio-reading check; do not repeat completed signal correlation or printed collation as new work.
- [x] Freeze the model/tool/source hashes, no-hint parameters, synthetic10second control and strict stop rule before inference.
- [x] Verify source, installed tool/model and passive parser pins; verify network-denial process profile.
- [x] Run one silent control, preserve nonempty output and classify the control FAILED despite inference exit0.
- [x] Stop without extracting/transcribing either intended court speech input; no tuning, model switch or retry.
- [x] Inspect actual WAV header/sample bytes, output and run/output directories; verify originals/model/engine unchanged.
- [x] Preserve prior report and all printed conflicts; exact additive Git diff retained.
- [x] Public derivative excludes court/raw audio, raw machine transcript/logs, weights, contacts/identities/private case material.
- [ ] Court speech reading, native media/custody/voice/source/clock tests: unperformed, not accepted.
- [ ] Original five-track/eighteen native-input acceptance criteria: open/partial, no acceptance from this method test.

Publication identity/ref/file verification is recorded separately after any authorized push. Successful file checks do not mean the speech-control test passed.

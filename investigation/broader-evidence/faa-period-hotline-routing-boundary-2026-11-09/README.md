## What the 2000 order covers

- **Intake and routing.** §§4 and 8 describe the Administrator’s and Consumer Hotline systems **AHIS** and **CHIS**, intake forms, computerized call records, action-office assignment and written responses. §5(b) includes complaints filed with DOT OIG among excluded matters. §5(c) separately provides for sending a copy to the Accountability Board coordinator in covered misconduct complaints. These are separate routing rules. The acquired order supplies no case-specific hotline intake or Board assignment for **042R0122001**. [Order pp. 1–3](https://www.faa.gov/documentLibrary/media/Order/ND/1070.1.pdf#page=2)
- **Response and closeout.** §8(f) gives a normal **14 calendar days** and an automatic **30 calendar days** for the designated Civil Aviation Security Operations office, with an extension route. §8(h) describes review of the hotline response before closeout. These are hotline fields and deadlines. Applying them to an OIG recommendation would require a documented case assignment and applicable authority. [Order p. 4](https://www.faa.gov/documentLibrary/media/Order/ND/1070.1.pdf#page=4)
- **Distinct record sets.** §9 lists search fields including control number, date, routing symbol and operator ID. §12 distinguishes intake and responses in DOT/FAA **845** from the underlying investigative records used to develop those responses. The previously reviewed 2006 Executive Secretariat order identifies the **AOA-3** controlled correspondence system as a separate route for incoming and outgoing case correspondence. [Order pp. 5–6](https://www.faa.gov/documentLibrary/media/Order/ND/1070.1.pdf#page=6) · [Executive Secretariat crosswalk](https://github.com/AveLyra/911-conspiracy-investigation/blob/2b030c70ecb95e0929661ba04df3e039b4db6942/investigation/broader-evidence/faa-aoa3-correspondence-control-2026-11-06/README.md)

November 5, 2026 · B129 / PD03–PD04. This review identifies where to look for FAA responses and employee-conduct follow-up on DOT OIG report **CC-2006-085**. ## Historical directive-to-office link

The FAA's **May 31, 2001** checklist, Figure 1, places **DOT 8000.5A → FAA 1600.38C**, office **ACP-300**, date implemented **5/8/96**. Appendix 1 gives the title *Employee and Other Internal Security Investigations*, the same **ACP-300** office and **5/8/96** issue date, and a separate **5/1/01** revalidation date. The text extractor misreads several digits, so the row values here are from the page images. The same Figure 1 separately places **DOT 8000.1 c → FAA 2900.1**, office **ABU-130**, date **7/5/85**, as preserved in the prior audit-follow-up crosswalk. These are separate implementation entries. ## Comparison with an actual response packet

The **July 19, 2012** DOT OIG audit on the Air Traffic Safety Action Program reproduces a **June 15, 2012** response memo from **AAE-1** to the OIG audit office. Its **Actions Required** section labels recommendations **1–8** “resolved but open pending” completion and separately requests a written response for **9 and 10** under DOT 8000.1C. It copies **AAE-100**. This packet supplies an observable example of an FAA response, a later OIG status and a tracking-office recipient in separate document fields. The numbered recommendations and timing in this example concern the **2012 audit** only.

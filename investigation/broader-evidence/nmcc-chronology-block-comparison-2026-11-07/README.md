# NMCC chronology blocks: matching row labels, different visible coverage

**November 7, 2026 — AUD016-A1; TEL03/TEL04; follow-up to NM-S02.** This review compares the two separately paginated two-page blocks in the official [NARA ISCAP 2012-156, document 14, part 2](https://www.archives.gov/files/declassification/iscap/pdf/2012-156-doc-14-part-2.pdf#page=19). It advances the telephone/operational-log source trail; it is not a calibrated call-time analysis.

**Result:** both blocks have the same ordered **16 left-column row labels**, representing **15 distinct label strings**. Two separate rows in each block carry **111421L**. There is no detected left-column timing-label change between these four pages. That result does not establish that every body word, redacted passage, underlying event or original record is identical.

## Visible differences remain unresolved

Two specific contrasts were observed on **A p.19 versus B p.21**:

- **111347L:** the region immediately after the visible **NMCC** text and before the monitoring/tracking language has different visible coverage. B leaves additional letters visible before a covered span; A covers more of that corresponding region. This report does not guess covered words or identify the redacted counterpart.
- **First 111421L row, the backbrief/update entry:** B visibly includes **in the** after **111630LSEP01** before the covered region. A's corresponding region is covered. Each form is retained separately; text from B is not inserted into A.

These observations establish a difference in the released pages' visible text/coverage, not its cause. Different redaction placement, different underlying source text, rendering/export differences or another process remain untested possibilities. No comparison of hidden content was attempted. The shared visible row subjects and matching time-label order are contrary evidence against claiming a demonstrated timing rewrite between these blocks.

## New underlying-record retrieval routes

The **111420L** entry, visible in both forms, describes personnel being directed to retrieve database information from shared directories in the Pentagon and save it on hard drives. This is a specific lead for the native directory/database, contemporaneous backup copies, storage locations, tasking/routing records and any completion acknowledgment. The text does not identify the redacted personnel here, establish that the directive was executed, show that it concerned this chronology file, or demonstrate present survival or destruction.

The **111626L** entry mentions computer locations for tasks and provision of paper copies. This supplies another record-location/distribution lead: task papers, recipient/routing lists, print copies and any accompanying index. It is not proof that those papers contained the missing chronology, recordings or telephone records.

The **111347L** and **111715L** telephone entries can also anchor requests for original telephone/update records if they can be joined to session/channel identifiers and the actual log system. Their appearance in two forms of this packet is not two independent corroborating sources.

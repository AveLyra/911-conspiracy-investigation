# FAA action and no-action records in released DOT OIG investigation files

Public derivative of the November 10, 2026 source review UTC · B129 / PD02–PD05, supporting PD01. Two redacted DOT OIG reports in release **FI-2013-0123** show where an FAA action decision or recommendation response can be recorded. In one case, a supplemental report gives the date FAA advised OIG of administrative action, reports a separate no-action reason and separately records OIG closure. In another, a follow-up report identifies the earlier report and FAA response as an attachment and lists which recommendations FAA accepted and declined. These cases provide specific record types to look for in **CC-2006-085 / 042R0122001**. ## Preserve these distinctions

- The same date **August 6, 2009** appears in both records. It is an FAA notification date in the Northwest Mountain narrative and the date of an earlier OIG report in the San Juan attachment inventory. The packet supplies no link between those documents.
- San Juan's rendered cover reads **I11A002SINV**. The sorted text layer returns **`Il 1A002SINV`**. The title uses **Foreign Facility Deviations** and the allegation heading uses **Foreign Flight Deviations**. Preserve both identifier representations and both terms as source locators. [Physical pp. 175–176](https://www.governmentattic.org/15docs/51DOT-OIGclosingDocs1stPages_2007-2012.pdf#page=175)
- The release letter describes a narrowed request for the first ten pages from the primary report or memorandum of **51 investigations**, with some later resolution pages included and intervening pages omitted. The case files and their attachments have wider scope than the selected release. An attachment reference, an attributed FAA response and a case-closure statement answer separate questions.

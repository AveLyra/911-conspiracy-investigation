# Flight 175 data-hold email: ZNY-426

## Source and scope

The [National Archives scan](https://catalog.archives.gov/medialz/dc-metro/rg-237/7419198-9-11-faa/5-Miscellaneous/e-Other/5-ZNY-426-Email.pdf) ([catalog 7604064](https://catalog.archives.gov/id/7604064)) was retrieved 2026-11-16: 14,806 bytes, SHA-256 `e31c83207ae1b866999f389fb8424c714235b52945166b27471925078b0da4df`. Both pages were visually inspected; physical page 2 is blank except scan-edge marks. The [NARA finding aid](https://www.archives.gov/research/foia/faa-finding-aid-72-83) separately describes ZNY-426 as “Retaining voice communications data for UAL175.”

## Observations

Physical page 1 is a September 17, 2001 11:33 AM email requesting a receipt. It asks the addressee to hold “all data reference UAL175 for 9/11/01” under Order 8020.11 in support of Aircraft Accident Package `ZNY-ARTCC-148`, dated 9/11/01, `1303Z`. It describes itself as a substitute for a teletype request and refers to an earlier conversation that morning. The finding-aid wording names voice communications; the actual email uses “all data.” Both descriptions are preserved without treating either as establishing the precise data inventory.

MuPDF text extraction reads the date in the body as `9711701`; visual inspection reads `9/11/01`. Preserve both observations: the extracted characters are not a reliable transcription of that date. The scan says “Receipt requested”; it contains no completed receipt or proof of implementation.

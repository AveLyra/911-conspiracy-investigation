# PDF version/locator limits

The official30-page DOT report and the429-page release packet are distinct acquired files with distinct hashes. The report is reproduced inside the packet with additional cover material, scans/OCR and ordering differences. Release physical76 is printed2; physical77 is printed3; physical78 is the report’s memorandum/introduction printed1. Preserve that order; a universal page offset would be misleading.

DOT-VERSION-COMPARISON.json is a heuristic nearest-text candidate list from a bounded nearby-page window. Low similarities (including the appendix region) and even identical empty extracted text are not reliable page identities. Its raw values are preserved as a method output. Selected report/appendix passages were read directly; no visual/content equivalence of every source page was established, and no missing page, tampering or suppression inference is made from the ordering/format difference.

The earlier official-host403 and this run’s200PDF are both acquisition observations. The current CIA-host200HTML remains a failed PDF retrieval, regardless of the successful HTTP status. Search-index text is not the missing PDF byte comparison.

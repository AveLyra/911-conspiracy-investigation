# Flight 175 accident-package teletype and Bridgeport response: ZNY-500

## Source and scope

The [NARA scan](https://catalog.archives.gov/medialz/dc-metro/rg-237/7419198-9-11-faa/4-UAL-175/e-Other/4-ZNY-500-Teletype-Message.pdf), [catalog 7598627](https://catalog.archives.gov/id/7598627), was retrieved November 16, 2026: four PDF pages, 87,683 bytes, SHA-256 `339820fbe718c728090ac05ea819df5412b40522689b1ca8aff9a913200de858`. Pages 1, 2 and 4 were visually inspected and all four pages text-extracted. The [finding aid](https://www.archives.gov/research/foia/faa-finding-aid-72-83) calls it a teletype message requesting accident data.

## Observations

Page 2 displays a September 17, 2001 message concerning UAL175 package `ZNY-ARTCC-148`, with routing codes `KZBWZRZX`, `KBDRYFYX` and `KZNYZQZX`. It requests that data concerning the aircraft be held and says, “IF YOU HAVE NO DATA, PLEASE FORWARD POSITIVE/NEGATIVE REPLIES TO ZNYZQZX.” Page 4 displays a freeform message screen addressed to `KZBWZRZX KBDRYFYX` with a different ending: “IF YOU HAVE NO DATA, PLEASE FORWARD NEGATIVE REPLIES TO ZNYZQZX.” Preserve both wordings; their preparation and transmission sequence is not independently established.

Page 1 displays a further message associated with `KBDRYFYX` and the same package identifier: “NEGATIVE CONTACT UAL175. 9/11/01” and `BDR QA`. The previously examined [ZNY-423 memorandum](https://github.com/AveLyra/911-conspiracy-investigation/blob/d5e213bfa526751f420fd3a6f2f7eabb110df3e6/investigation/broader-evidence/faa-zny-423-hold-2026-11-16/README.md) associates `KBDRYFYX` with Bridgeport flight service station. This is a specific responsive message to investigate, not proof that the facility possessed no records of any kind. The display contains times and message codes whose clock basis and routing interpretation have not been independently checked.

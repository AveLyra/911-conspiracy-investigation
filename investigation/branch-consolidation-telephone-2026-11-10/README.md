# Telephone source-branch consolidation — November 10, 2026

This catalog preserves **33 files across 4 dated research groups** already published on AveLyra topic branches. Source files are copied byte-for-byte as Git blobs, without merging the source branches or deleting any history. The [source manifest](SOURCE-MANIFEST.json) records each original public ref, source commit, blob and SHA-256. This index is not a new source verification or a count of independent findings.

The source reports are dated historical research. Statements such as “not published,” “not yet located,” or “pending” describe their original date and are not a live status assertion. Studies can overlap or supersede one another. Local-only material, flagged sensitive groups, private case material and Git LFS objects were not included in this batch. Relative Markdown target existence was screened; source rights, every underlying scientific claim, scripts, JSON dependencies, external URLs and remote source availability were not all independently revalidated.

These reports discuss telephone-related records and preserve their source and attribution limits. They do not establish the contents or authenticity of inaccessible recordings, or the accuracy of an identity solely from a name match.
